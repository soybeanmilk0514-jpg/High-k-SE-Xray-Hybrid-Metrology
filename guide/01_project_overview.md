# 01. Project Overview

## Research Question

ALD 기반 High-k 초박막에서 SE 단독 역모델링으로는 분리하기 어려운 **두께·광학상수·거칠기 간 parameter correlation**을, 독립적인 X-ray 구조 정보를 이용해 줄일 수 있는가?

## Project Flow

1. advanced-node High-k metrology problem 정의
2. ALD 초기 성장과 계면층 형성 검토
3. SE 측정 원리와 inverse-model ambiguity 분석
4. XRD/XRR 원리와 단독 측정 한계 분석
5. X-ray-derived parameter를 SE 모델의 fixed constraint로 넣는 feed-forward 개념 제안
6. published hybrid-metrology case study로 fixed vs floating parameter 차이 해석
7. High-k density / interface roughness 정량화 관점으로 적용 가능성 정리

## Project Type

본 프로젝트는 직접 웨이퍼를 측정한 실험 프로젝트가 아니라, 문헌과 계측 원리를 바탕으로 한 **semiconductor metrology analysis & proposal project**다.

따라서 이 저장소에서는 published values를 original experimental result로 표현하지 않는다.
