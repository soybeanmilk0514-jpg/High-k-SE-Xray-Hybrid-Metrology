# 08. Application to ALD High-k Characterization

## Proposed Use

프로젝트가 제안한 High-k 분석 흐름은 다음과 같다.

### X-ray side

XRR/X-ray measurement에서 가능한 구조 정보를 먼저 확보한다.

- physical thickness
- density-related information
- interface/surface roughness trend

### SE side

이 structural information을 optical inverse model의 prior / fixed constraint로 사용한다.

남은 fitting freedom을 다음과 같은 optical response 해석에 집중시킨다.

- refractive index
- extinction coefficient where applicable
- layer-by-layer optical contrast
- density-related optical contrast

## Expected Benefit

프로젝트에서 기대한 효과는:

- thickness–n correlation 감소
- roughness와 thickness 사이의 ambiguity 감소
- multilayer model의 convergence 개선
- interfacial layer와 bulk-layer distinction의 신뢰도 향상

## What Is Not Demonstrated

본 교과 프로젝트에서는 실제 HfO₂ wafer에 대해 SE-only / XRR-only / hybrid를 동일 시편에서 직접 비교하는 experiment를 수행하지 않았다.

따라서 “몇 % 정확도 향상”과 같은 자체 성능 수치를 주장하지 않는다.
