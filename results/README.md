# Results

This project did **not** generate original SE/XRR wafer-measurement data.

The CSV files in this directory summarize **published case-study values used in the conference presentation** so that the evidence remains clearly separated from original experimental results.

## Files

- `literature_case_study.csv`
  - quantitative comparison used to explain fixed vs floating parameters
  - values were taken from the published hybrid-metrology example used in the presentation
- `project_claims.csv`
  - separates proposed High-k application from directly demonstrated literature evidence

For the interpretation and scope, see [guide/07_literature_case_study.md](../guide/07_literature_case_study.md).
